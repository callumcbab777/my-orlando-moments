# My Orlando · Moments

Internal concept demo (ABI Group / AMBAR Orlando) of the **My Orlando → Moments** area of the buyer portal: seven clickable Moment cards, a detail view for each, and a "board that fills in" (click *Mark as shared*). Shared state is kept only in the viewer's browser (localStorage).

Fully static and self-contained: fonts (Cormorant Garamond, DM Sans — SIL OFL), AMBAR logo and photos are bundled. No CDN, no tracking. Open `index.html` or serve the folder.
